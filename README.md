# 🎬 VisionCraft AI

**VisionCraft AI** is an AI-powered cinematic video creation studio built with **Python and Streamlit**.

Transform simple ideas into cinematic video concepts with AI-powered prompt enhancement, image-to-video workflows, and scene-by-scene story generation.

## ✨ Features

* 🎬 Text-to-video prompt creation
* ✨ Cinematic AI prompt enhancement
* 🖼️ Image-to-video workflow
* 🎞️ Scene-by-scene generator
* 🎨 Multiple visual styles
* 🎥 Cinematic camera movement options
* 📐 Multiple aspect ratios
* 📁 Project management system
* ⚙️ Custom generation settings
* 🌌 Futuristic dark interface

## 🛠️ Tech Stack

* Python
* Streamlit
* Requests
* Pillow
* Python Dotenv

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/VisionCraft-AI.git
```

### 2. Open the project folder

```bash
cd VisionCraft-AI
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
